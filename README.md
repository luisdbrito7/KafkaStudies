# Estudos com Apache Kafka

Repositório dedicado aos meus estudos práticos sobre **Apache Kafka**, explorando sua integração com Java e Spring Boot e os principais conceitos de mensageria e comunicação assíncrona.

## Objetivos

- Compreender os fundamentos do Apache Kafka.
- Aprender sobre produtores (*producers*) e consumidores (*consumers*).
- Trabalhar com tópicos (*topics*) e mensagens.
- Integrar Kafka com aplicações Java e Spring Boot.
- Entender a importância da comunicação assíncrona em sistemas distribuídos.

## Tecnologias utilizadas

- Java
- Spring Boot
- Apache Kafka
- Docker
- Git e GitHub


## Objetivo do projeto

Consolidar conhecimentos em mensageria e desenvolvimento back-end, documentando minha evolução prática com Apache Kafka e seu uso em aplicações Java.
